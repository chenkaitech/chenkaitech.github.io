# CXY Studio

CXY Studio is an independent iOS app studio by Kai Chen. The catalog brings together 33 focused iPhone apps for everyday productivity, privacy, health, creativity, home life, and more.

**Browse the live directory:** [chenkaitech.github.io](https://chenkaitech.github.io/)

**Developer page on the App Store:** [Kai Chen](https://apps.apple.com/il/developer/kai-chen/id1818964633)
